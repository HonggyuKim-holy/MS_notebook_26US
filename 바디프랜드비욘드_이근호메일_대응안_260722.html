이근호 소장 검토 메일(7/22) — 항목별 대응안

임원 의견 수렴용 · 제안서 v18 기준 · 결정 후 v19에 일괄 반영

총평 — 다섯 항목 모두 반대가 아니라 "보고 라인에서 되돌아오지 않게 미리 메워라"는 실무 코치입니다.
소장이 이 제안서를 내부에서 통과시키기 위해 방어 포인트를 미리 알려주는 것으로 판독합니다.

채택 권고1. 투트랙 정합 · 통합로그인 사실 정정

"운영성 기능은 기존 앱, 리포트·코인은 새 앱 — 고객 경험 정의가 필요. 그리고 리모컨 계정은 이미 자사 통합로그인과 연동되어 있어 '9월부터 계정 결합 수집 본격화'는 확인이 필요."
판단

후반부는 사실 정정이라 반드시 반영해야 합니다. 통합로그인이 이미 연동돼 있다는 것은 소장이 준 정확한 내부 사실 — 현재 2p의 "계정과 결합되기 시작합니다"는 반박당할 수 있는 표현입니다.

반영안
2p 헤드라인: "9월, 계정 결합이 선택에서 기본으로 바뀝니다." — 지금도 통합로그인은 있으나 선택 사항(소수), 마사지맵부터는 사실상 기본. 사실에 정확하고 임팩트는 유지.
9p 투트랙 카드에 한 줄: "비욘드 앱에서 서비스 기능(이전설치·렌탈·결제)은 기존 앱으로 바로 연결합니다." — "고객이 두 앱을 헤맨다" 반론 차단.

부분 채택 권고2. 판정 기준의 구체화 (전액 지급과 신뢰)

"전액 지급 뒤 4주차에 목표치를 정하면 기준을 낮춰 맞출 여지가 있다 — 조정 불가 항목을 정해달라."
판단

펀드가 반드시 던질 질문을 소장이 미리 알려준 것. 다만 실측 전에 최소 수치를 박는 것은 우리 목을 거는 족쇄라 반대합니다. 숫자가 아니라 구조를 고정하는 절충안을 제안합니다.

반영안 (절충)
  • 판정 지표 4종은 고정(조정 불가): 로그인 전환율 · 기기 연동율 · 케어 리텐션 · 코인 사용률 — 4주차에 정하는 것은 목표치(숫자)뿐
  • 합의 불발 시 기본값: 7월 16일 발표에서 리체가 스스로 공표한 기준(4주 정착률 25% 등)을 적용 — 새 족쇄가 아니라 이미 공개한 약속의 재사용이며, 불발 처리까지 답이 됨

이 선을 넘는 "최소 수치 명기"는 반대 — 실측 전 숫자는 지키지 못할 약속이 됩니다.

부분 채택 권고3. 혜택 비용의 부담 주체·산식

"혜택 비용(씨앗 2~5억 / 확산 40~85억)은 개발비와 별개로 당사가 지속 지출할 재원 — 마스터플랜에 부담 주체와 산식을 포함해달라."
판단

요구 지점이 "제안서에 명시"가 아니라 "마스터플랜(납품물)에 포함"이므로 부담이 없습니다. 우리는 이미 산식·변수표·시나리오를 갖춘 혜택 원가 모델 v1을 내부에 만들어 둔 상태 — 소장 요구가 곧 그 문서의 스펙입니다.

반영안
6p 밴드의 납품물 설명 확장: "원가 모델과 리워드 예산안(산식·재원 부담 구조 포함)은 계약 ①의 정식 납품물입니다."

채택하되 결정 필요4. 수행 역량 부록 (팀 구성)

"AI 네이티브·1,200만 실적의 근거와 투입 인력 구성(직군·규모·정규/외주)을 부록으로 — 계약 시점엔 이력서까지 요청받을 확률이 높다."
판단

계약 실무의 예고편을 미리 알려준 값진 정보. 본문 13장의 담백함은 유지하고, 부록 1장(14p)으로 분리하는 것을 권합니다. 실명·이력서는 계약 시점 대응으로 미루고, 부록에는 직군별 구성·전담 여부·핵심 경력 요지까지만.

결정 필요
  • 부록에 담을 직군 구성·인원 규모·정규/외주 여부 — 실제 정보 필요 (대표 제공)
  • 노출 수위 — 어디까지 보여줄지 (예: "기획 N · 개발 N · 데이터 N · 혜택소싱 N, 전원 전담" 수준 권장)

채택 권고5. 데이터 최소 제공 · 보안 통제

"ISMS-P 심사 중이라 개인정보·민감데이터 외부 제공은 통제 필요 — 제공 항목을 최소한으로 특정하고 접근·보관·반출 통제를 인프라팀과 함께 정하자. NDA는 범위 정리되는 대로."
판단

비용 0, 효과 최대. 이 한 줄이 법무·보안 라인 통과의 열쇠이며, 우리의 "자료 무관 착수 가능" 구조(10p)와도 정합 — NDA·범위 정리가 늦어도 계약은 갑니다. (ISMS-P 언급 자체는 그쪽 내부 정보라 문서엔 쓰지 않음)

반영안
12p "고객 정보 보호" 불릿 확장: "데이터는 고객 동의와 법령의 범위 안에서만 — 제공 항목은 검증에 필요한 최소한으로 특정하고, 접근 인원·보관·반출 통제는 바디프랜드 보안 절차를 따릅니다."

결정이 필요한 것 (임원 의견 수렴 대상)

  • A. 항목 1·3·5 — 위 반영안대로 진행해도 되는가 (권고: 즉시 채택)
  • B. 항목 2 — "지표 4종 고정 + 불발 시 발표 기준 기본값" 절충 수위가 적정한가, 아니면 아예 뺄 것인가
  • C. 항목 4 — 부록 신설 여부와 팀 구성 정보의 노출 수위
